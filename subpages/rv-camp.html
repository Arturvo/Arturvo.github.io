Gas Station Simulator - RV Camp DLC

RV Camp is a DLC for Gas Station Simulator that introduces campground management. Players rent pitches to travellers, complete minigames to help guests pass the time, and expand the campsite while helping Ruby develop the resort.

My Contributions

RV Camp DLC was my first project as a team lead. I established the DLC's structure and built its core systems on top of the existing base game. My role combined hands-on programming with team leadership, with a particular focus on the underlying systems that tied the experience together, particularly camper booking and lifecycle. I was also responsible for managing the project's build pipeline and version control.

Below are the key features and areas I was responsible for:

Project Management

  • Managed the build pipeline using Perforce and Jenkins to keep builds reliable and support smooth transitions between products and configurations.
  • Managed version control in Perforce across multiple departments, keeping branches consistent and coordinating changes to minimise conflicts.
  • Coordinated programming work with QA to ensure the intended changes were included in builds submitted for testing and releases.

RV Driving and Life Cycle

  • Developed a vehicle life cycle system covering spawning, driving to camp spots, and despawning, with a state machine to manage transitions between states.
  • Implemented camp spots that players can rename and unlock as they progress through the game.

RV Booking

  • Developed a system for booking and managing guests.
  • Implemented multiple guest types with distinct requirements and life cycles, with easily accessible settings for designers.
  • Implemented a complex economy system that provides different rewards based on guest types and the conditions of their stay.
  • Implemented the complete user interface from a design mockup.

Game Progression System

  • Implemented an upgrade system that lets players spend currency to unlock new content and advance the quest line.
  • Collaborated with the team to adapt other DLC systems to work with the upgrade system.
  • Implemented the complete user interface from a design mockup.

Employee System

  • Implemented a system for assigning and managing RV Camp employees, including their associated costs and rewards.
  • Implemented employee NPCs that perform tasks at their assigned workstations.
  • Implemented the complete user interface from a design mockup.
